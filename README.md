## GitHub Pages setup

1. Upload index.html, .nojekyll, and this README.md to the repository root on the main branch.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select main, / (root), and **Save**.
5. After deployment, open the public URL above in a private/incognito window and verify it loads without signing in.

Do not upload application source code, signing keys, account documents, or private contact details to this repository.
