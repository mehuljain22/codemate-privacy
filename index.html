1. Scope

This Privacy Policy explains how CodeMate — Your Pocket Coding Companion (com.codemate.pocketide) accesses and handles information when you use the Android app. It applies to the CodeMate app published by the entity identified above.

CodeMate is designed to work without an account or cloud service. The release described by this policy does not contain advertising, analytics, telemetry, or a developer-operated backend, and its Android manifest does not request the Internet permission.

2. Information handled only on your device

CodeMate can access and process the following information locally so that its features work:

  • the profile name you choose during onboarding;
  • projects, folder and file names, source code, and imported files;
  • editor preferences, theme, recent-project state, bookmarks, and session data;
  • coding-streak and successful-run counters;
  • personal learning notes and scratchpad text;
  • SQLite databases created in the app; and
  • program input, compiler messages, terminal output, and preview content.

This information stays in CodeMate's app storage unless you explicitly use an import or export action. On-device access and processing are not transmitted to the developer and are not used for advertising or profiling.

3. Collection, sharing, and sale

CodeMate does not transmit personal or sensitive user data to the developer or to third parties. The developer therefore does not collect, share, or sell the locally processed information listed above.

Google Play, Android, a device manufacturer, or an operating-system service may separately process installation or device diagnostics under its own terms and privacy policy. That processing is not performed by CodeMate's app code.

4. Importing and exporting files

Import and export are user-initiated. CodeMate uses Android's system document or folder picker, and receives access only to the document or location you select. If you choose a cloud-backed document provider or another app as the destination, that provider may copy the selected content off your device under its own privacy policy. CodeMate does not silently upload projects or source code.

Exported copies are outside CodeMate's private storage. Deleting the original inside CodeMate does not delete copies that you exported elsewhere.

5. Local code execution

CodeMate runs supported code in local execution environments. Program input and output are processed on the device. Code you run may read or change files made available to that execution environment, consume device resources, or produce unexpected output. Run only code you understand and trust.

CodeMate does not download compilers or executable code from the Internet. The exact supported runtimes and their limitations are described in the app and its store listing.

6. Security

CodeMate uses Android app-scoped storage for private data, disables Android backup and device-to-device transfer for that data, does not request broad storage access, and limits document access to selections made through the Android system picker. Network loads are disabled in CodeMate's local preview and execution WebViews.

No security measure can eliminate every risk. A device compromise, malicious code, an unsafe exported location, or another app or provider chosen by you can affect information outside CodeMate's protections.

7. Retention and deletion

Local information remains on the device until you edit or delete it, empty a project's recycle bin, clear CodeMate's app storage in Android settings, or uninstall CodeMate, subject to Android's normal device behavior.

Deleting a complete project removes its local project directory after confirmation. Deleting an individual project file or folder first moves it to that project's recoverable recycle bin; it remains there until restored or the recycle bin is emptied. CodeMate has no remote account and keeps no server-side copy, so there is no online account-deletion process.

Before clearing storage or uninstalling, export any project you want to keep. You must separately delete copies exported to another location or provider.

8. Children and target audience

CodeMate does not knowingly collect personal data from children or other users because it does not transmit personal data off the device. The intended audience is ages 13 and older (13–15, 16–17, and 18+ in Google Play). CodeMate is not designed for children under 13. The publisher must still follow any Families and child-privacy requirements that apply in a launch country.

9. Changes to this policy

If CodeMate's data practices change, this policy and the Google Play Data safety declaration must be updated before the changed app is distributed. The effective date at the top of this page identifies the governing version.
